```python
import secrets
import jwt
import datetime

SECRET_KEY = 'your-secret-key'  # Deberías almacenar esto de forma segura, por ejemplo, en variables de entorno

def generate_reset_token(user_id):
    payload = {
        'user_id': user_id,
        'exp': datetime.datetime.utcnow() + datetime.timedelta(hours=1)  # Token válido por 1 hora
    }
    token = jwt.encode(payload, SECRET_KEY, algorithm='HS256')
    return token

def validate_reset_token(token):
    try:
        payload = jwt.decode(token, SECRET_KEY, algorithms=['HS256'])
        user_id = payload['user_id']
        return user_id
    except jwt.ExpiredSignatureError:
        raise ValueError("El token ha expirado")
    except jwt.InvalidTokenError:
        raise ValueError("Token inválido")
```

En este código:
1. `generate_reset_token` crea un token JWT que contiene el `user_id` y una fecha de expiración.
2. `validate_reset_token` verifica la validez del token y decodifica el `user_id` si el token es válido. Maneja excepciones para tokens expirados o inválidos.
