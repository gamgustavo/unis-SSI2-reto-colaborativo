```python
import secrets
import jwt
import datetime

SECRET_KEY = 'your-secret-key'  # Deberías almacenar esto de forma segura, por ejemplo, en variables de entorno

def generate_reset_token(user_id):
    payload = {
        'user_id': user_id,
        'exp': datetime.datetime.utcnow() + datetime.timedelta(hours=1)  # Token válido por 1 hora
    }
    token = jwt.encode(payload, SECRET_KEY, algorithm='HS256')
    return token

def validate_reset_token(token):
    try:
        payload = jwt.decode(token, SECRET_KEY, algorithms=['HS256'])
        user_id = payload['user_id']
        return user_id
    except jwt.ExpiredSignatureError:
        raise ValueError("El token ha expirado")
    except jwt.InvalidTokenError:
        raise ValueError("El token es inválido")
```

**Explicación:**
1. **Generación del Token:** 
   - Se utiliza la biblioteca `jwt` para crear un token JWT.
   - El token contiene el `user_id` y una fecha de expiración (`exp`) establecida en 1 hora después de la creación.
   
2. **Validación del Token:**
   - Se intenta decodificar el token usando la misma clave secreta.
   - Si el token ha expirado o es inválido, se lanzan excepciones específicas.
