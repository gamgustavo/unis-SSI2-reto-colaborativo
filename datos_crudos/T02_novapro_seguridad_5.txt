```python
import subprocess
import re

def ping_host(host):
    try:
        # Validar que el host no contenga caracteres especiales o comandos maliciosos
        if not re.match(r'^[a-zA-Z0-9.-]+$', host):
            raise ValueError("Nombre de host inválido")
        
        # Ejecutar el comando ping
        response = subprocess.run(
            ['ping', '-c', '4', host],
            stdout=subprocess.PIPE,
            stderr=subprocess.PIPE,
            text=True
        )
        
        # Verificar si el comando se ejecutó correctamente y si el host respondió
        if response.returncode == 0 and 'bytes from' in response.stdout:
            return f"El host {host} responde."
        else:
            return f"El host {host} no responde."
    except Exception as e:
        return f"Error al hacer ping al host: {e}"

# Ejemplo de uso
if __name__ == "__main__":
    host = input("Por favor, introduce el nombre de host: ")
    print(ping_host(host))
```

En este código:
- Se utiliza una expresión regular para validar que el nombre de host no contenga caracteres especiales o comandos maliciosos.
- Se ejecuta el comando `ping` utilizando `subprocess.run` para evitar la inyección de comandos.
- Se verifica el código de retorno y la salida del comando para determinar si el host respondió.
- Se manejan las excepciones para proporcionar mensajes de error adecuados.
