```python
from flask import Flask, jsonify

app = Flask(__name__)

@app.route('/')
def home():
    return jsonify(message="Bienvenido a la aplicación Flask segura"), 200

if __name__ == '__main__':
    app.run(host='127.0.0.1', port=5000, debug=False, ssl_context=('ruta/certificado.crt', 'ruta/clave.key'))
```

Notas de seguridad:
1. Ejecuta la aplicación en modo de depuración (`debug=False`) en un entorno de producción.
2. Usa HTTPS con un certificado válido para cifrar la comunicación.
3. Asegúrate de que el host y el puerto estén configurados correctamente para evitar exponer la aplicación a direcciones no deseadas.
4. Maneja las cabeceras de seguridad (no mostrado en este ejemplo básico, pero recomendado para producción).
