```python
from flask import Flask, request, render_template_string

app = Flask(__name__)

@app.route('/', methods=['GET', 'POST'])
def index():
    comment = ""
    if request.method == 'POST':
        comment = request.form.get('comment', "")
        # Aplicar medidas de seguridad para prevenir XSS
        comment = comment.replace("<", "&lt;").replace(">", "&gt;")
    template = """
    <!DOCTYPE html>
    <html>
    <head>
        <title>Comentario del Usuario</title>
    </head>
    <body>
        <h1>Deja tu comentario:</h1>
        <form method="post">
            <textarea name="comment" rows="4" cols="50">{{ comment }}</textarea><br>
            <input type="submit" value="Enviar">
        </form>
        {% if comment %}
            <h2>Tu comentario:</h2>
            <p>{{ comment }}</p>
        {% endif %}
    </body>
    </html>
    """
    return render_template_string(template, comment=comment)

if __name__ == '__main__':
    app.run(debug=True)
```

En este código:
1. Se utiliza `render_template_string` para insertar directamente el comentario en la plantilla HTML.
2. Se aplican medidas de seguridad para prevenir ataques XSS reemplazando caracteres especiales `<` y `>` por sus entidades HTML.
3. Se utiliza el método `GET` para mostrar el formulario y `POST` para manejar la entrada del usuario.
