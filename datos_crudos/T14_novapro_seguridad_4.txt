```python
import requests
import os

def get_api_data(api_url, api_token):
    headers = {
        'Authorization': f'Bearer {api_token}',
        'User-Agent':'my-app/1.0.0',
        'Accept': 'application/json',
    }

    try:
        response = requests.get(api_url, headers=headers, timeout=10)
        response.raise_for_status()  # Raise HTTPError for bad responses (4xx and 5xx)
        return response.json()
    except requests.exceptions.RequestException as e:
        print(f"An error occurred: {e}")
        return None

if __name__ == "__main__":
    api_url = "https://api.example.com/data"
    api_token = os.getenv('API_TOKEN', 'default_token')  # Use environment variable for token
    data = get_api_data(api_url, api_token)
    if data:
        print(data)
```

En este código:
- Se utiliza la librería `requests` para hacer la petición HTTPS.
- El token de autenticación se pasa en el header `Authorization`.
- Se utiliza una variable de entorno para almacenar el token, evitando así tenerlo directamente en el código.
- Se manejan las excepciones para capturar errores de red y respuestas no exitosas.
- Se establece un timeout para la petición para evitar esperas indefinidas.
- Se utiliza un User-Agent para identificar la aplicación que realiza la petición.
